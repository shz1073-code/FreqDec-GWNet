# 技术路线 19.6：最终防守执行版

## 0. 目标

19.6 是最终防守执行版。它不改变 19.5 的主方法，只把三个实验防守点落到实现层：

1. Smart reference selection。
2. Drift / cycle-consistency evaluation。
3. Variable frame-rate and dropped-frame robustness test。

## 1. ReferenceSelector

### 1.1 文件建议

```text
reference_selector.py
```

### 1.2 默认策略

优先级：

1. clinical roadmap/mask reference frame。
2. best frame within initial warm-up frames。
3. first frame baseline。

### 1.3 warm-up reference scoring

在每段 burst 的前 `N=5` 到 `10` 帧中计算：

```text
score_t = image_sharpness_t + anchor_quality_t - state_change_t
```

其中：

```text
state_change_t = ||s_t - s_{t-1}||
```

选择：

```text
r = argmax(score_t)
```

第一版可简化：

- `image_sharpness`: Laplacian variance。
- `anchor_quality`: 来自 state label quality report。
- `state_change`: 使用预测或弱标签状态变化。

### 1.4 必做报告

报告：

- chosen reference index。
- reference score components。
- first-frame baseline vs smart reference。

## 2. Drift Evaluation

### 2.1 必做文件

```text
evaluate_drift.py
```

### 2.2 必做指标

对每条测试序列输出：

- compensation error vs frame index。
- cumulative drift curve。
- landmark residual before/after compensation。

保存：

```text
reports/drift/{sequence_id}.csv
reports/drift/{sequence_id}.png
```

### 2.3 Cycle-consistency

如果存在近似回到参考状态的帧 `K`：

```text
E_cycle = ||U_K - U_ref||
```

判定 near-cycle 可用：

```text
||s_K - s_ref|| < threshold
```

或使用 phase bin 回到 reference bin 且 amplitude 接近。

若没有完整周期：

- 不强行计算。
- 报告 not available。
- 用 cumulative drift curve 替代。

### 2.4 Reference reset 可选增强

冲 TMI 时可实现：

```text
if anchor_quality_t > tau_q and drift_t > tau_d:
    set r = t
    U_t = 0
```

第一版可作为 ablation，不强制进入主模型。

## 3. Mamba/GRU Robustness Stress Test

### 3.1 固定帧率主实验

先做正常测试：

- GRU
- Mamba
- same sampler
- same loss
- same detach
- same burn-in

### 3.2 丢帧测试

测试设置：

```text
drop_rate in {0.1, 0.2, 0.3, 0.5}
```

报告：

- phase correlation。
- centerline jitter。
- compensation error。
- drift reduction。

### 3.3 降采样帧率测试

例如：

```text
15 fps -> 7.5 fps
15 fps -> 5 fps
```

若原始数据有真实 fps，按真实 fps 记录。

### 3.4 Δt 输入

如果进行 irregular interval 测试，建议给 state branch 输入 time gap：

```text
z'_t = concat(z_t, delta_t_embedding)
```

最小实现：

```text
delta_t_norm = delta_t / median_delta_t
z'_t = concat(z_t, delta_t_norm)
```

若不输入 `Δt`，论文不能声称模型显式感知时间间隔，只能说 evaluated under dropped-frame input.

### 3.5 写作原则

不能预设：

```text
Mamba must outperform GRU.
```

只能写：

```text
We evaluate whether temporal Mamba provides additional robustness under irregular sampling and frame-drop conditions.
```

若 Mamba 不明显优于 GRU：

- 题目不写 Mamba。
- Mamba 作为 state core 消融保留。

## 4. L_motion 表述与实现

### 4.1 主配置

```yaml
detach_prev_feature: true
detach_curr_feature: true
detach_state_input: false
```

解释：

- `L_motion` 主配置优化 state-conditioned motion mapping。
- 不直接优化 encoder/decoder feature representation。
- 分割前端由 segmentation/localization losses 负责。

### 4.2 消融配置

```yaml
feature_adaptive:
  detach_prev_feature: false
  detach_curr_feature: true
```

用途：

- 测试让上一帧特征适配 motion loss 是否改善 compensation。
- 若伤害 segmentation，则不作为主配置。
